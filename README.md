# ShopNex

A full-stack e-commerce web application built on the MERN stack (MongoDB, Express, React, Node.js).

## 🚀 Live Demo

- **Frontend:** [https://shopnex-website-1.onrender.com](https://shopnex-website-1.onrender.com)
- **Backend API:** [https://shopnex-website.onrender.com](https://shopnex-website.onrender.com)

## 🛠️ Tech Stack

**Frontend**
- React (Vite)
- Deployed as a static site on Render

**Backend**
- Node.js + Express
- MongoDB (Atlas) with Mongoose
- JWT-based authentication
- AWS S3 for image storage

**Infrastructure**
- Render (Web Service for backend, Static Site for frontend)
- MongoDB Atlas (hosted database)

## ✨ Features

- User authentication (signup/login) with JWT
- Product listing and browsing
- Admin panel for product management
- Image uploads to AWS S3
- Responsive UI
